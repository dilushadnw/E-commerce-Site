QUICK START (5 MINUTES)
================================================================================

1. CREATE FIREBASE PROJECT (2 min)
   → Go to: https://console.firebase.google.com/
   → Click "Add project"
   → Name it (e.g., "trendy-threads")
   → Disable Google Analytics (optional)

2. ENABLE SERVICES (2 min)
   → Authentication: Enable Email/Password and Google
   → Firestore: Create database in test mode
   → Storage: Get started in test mode

3. GET CONFIG & UPDATE CODE (1 min)
   → Project Settings → Your apps → Web
   → Copy the firebaseConfig object
   → Paste in js/app.js (line 3-10)
   → Paste in js/admin.js (line 23-30)

4. TEST LOCALLY
   VS Code:
     → Install "Live Server" extension
     → Right-click index.html → "Open with Live Server"
   
   OR Python:
     → python -m http.server 8000
     → Open http://localhost:8000
   
   OR npm:
     → npx http-server -p 8000

5. CREATE ADMIN USER
   → Register on your site
   → Go to Firebase Console → Firestore
   → Find your user in "users" collection
   → Add field: role = "admin"

6. ADD PRODUCTS
   → Go to /admin.html
   → Use "Add Product" tab
   → Upload images and fill details
